# CURSO DE JS AUTODIDACTA
## Objetivo.

Este repositorio tiene como objetivo guardar todo el camino que he llevado en el aprendizaje del lenguaje de javascript y servir como apoyo para alguien mas si lo encuentra.

### Contenidos.
* BASES DE JS (Nivel avanzado): 

     Doy por hecho que si estas aprendiendo js ya debes tener alguna base en otro lenguaje por lo que omito muchos de los conceptos que son iguales en otros lenguajes para no hacer tan extensas las notas. 

* JS PARA APLICACIONES WEB:

    Este apartado se centra en las funciones que tiene JS para darle interacciones reales a las paginas web y tengan personalidad propia, es la parte mas importante de lo que busco aprender.
